# Focus Window AppImage

**Focus Window** adalah skrip Python untuk memfokuskan window tertentu di Linux jika:
- Window tersebut dalam keadaan tidak aktif (blur)
- Mouse dalam keadaan idle selama 5 detik
- Nama window cocok dengan keyword tertentu (dengan regex)

Skrip ini dibungkus dalam format **AppImage** agar bisa dijalankan secara portabel di berbagai distro Linux tanpa harus menginstal Python atau dependensi secara manual.
